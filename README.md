# Chain_QTE_Bot
This is a QTE (Quick Time Event) bot for a Roblox game titled "Chain."
How to Use?
1. Open Roblox
2. Open the app
3. Enter the game
4. Click Enable
5. Enjoy it

Note! Please download the 'Assets' folder as well, and keep both the 'Assets' folder and the 'Chain_QTE_Bot.py' file in the same directory (this is required for Template Matching to function).
Thank you for reading it

If the app fails to open, create a .bat file containing the content below.

@echo off
chcp 65001 >nul

start "QTE Bot" cmd /c "python Chain_QTE_Bot.py"

exit
